# Café Komorebi

A cozy café-management game: a young graduate who can talk to animals helps Grandma run her café in the hillside town of Komorebi-chō, with Moka the concierge cat, Biscuit the husky and the Crumb Crew mice.

- **Play online:** https://myriambs.github.io/cafe-komorebi/game/dist/
- **Play offline:** open `game/dist/index.html` in Chrome, Edge or Firefox (double-click). See `game/README.md` for development.
- `game/` — the game (Vite + TypeScript + Three.js), levels 1–3
- `characters/` — character sheet (hand-drawn SVG cast) and diorama renders
- `interior/` — early interior and coffee-station mockups
- `template.html`, `build.sh`, `cafe-*.html` — the 3D exterior diorama (morning / sunset / night)
